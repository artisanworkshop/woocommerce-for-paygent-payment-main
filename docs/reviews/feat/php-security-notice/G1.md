### [G1-1][Copilot][誤検知][woocommerce-for-paygent-payment-main.php:85]
WP 5.0〜5.4 の `gettext` フィルターは 2 引数しか渡さないので、3 引数必須の callback が ArgumentCountError になる、という指摘。/ 判定: 保留（誤検知）
**対応:** WordPress 5.0 `wp-includes/l10n.php:182`・5.4 `:187` とも `apply_filters( 'gettext', $translation, $text, $domain )` で 3 引数を渡している（5.5 で増えたのは `gettext_{$domain}` フィルター）。修正なし / スレッド: https://github.com/artisanworkshop/woocommerce-for-paygent-payment-main/pull/46#discussion_r4354300885

### [G1-2][Codex][誤検知][includes/artws-php-security-notice/class-notice.php:458]
WP 5.0 の `WP_Scripts::do_item()` は src=false のハンドルで `wp_add_inline_script()` の内容を出力する前に return するので、ダイアログが開かない、という指摘。/ 判定: 保留（誤検知）
**対応:** WordPress 5.0 `class.wp-scripts.php:315-325` は `if ( ! $src ) { if ( $inline_script_tag ) { … echo $inline_script_tag; } return true; }` でインラインスクリプトを出力してから return する。管理画面の連結時も `in_default_dir( false )` が false なので `ext_handles` 側に進み、同じ分岐に届く。共通コピーの修正不要 / スレッド: https://github.com/artisanworkshop/woocommerce-for-paygent-payment-main/pull/46#discussion_r4354379102
