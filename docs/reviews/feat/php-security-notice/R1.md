## 指摘
### [R1-1][Medium][woocommerce-for-paygent-payment-main.php:50]
同梱訳の補完は `gettext_{$domain}` フィルターに頼っているが、このフィルターは WP 5.5 で追加された（l10n.php の `@since 5.5.0` で確認）。
プラグインの最低対応は WP 5.0 なので、5.0〜5.4 では補完が一度も動かず、言語パックが新規 9 文字列を訳していない日本語サイトで通知が英語になる。
計画・CLAUDE.md の「WP 6.5 未満は MO で補う」とも食い違う。
**修正方針:** 汎用の `gettext` フィルター（3 引数）に掛け、テキストドメインが違えば素通しにする。

### [R1-2][Medium][woocommerce-for-paygent-payment-main.php:91-96]
参照実装に無い MO 分岐（`WP_Translation_File` の無い WP 向け）を自動テストしていない。CI の integration は最新 WP だけで、unit は `__` が stub のため補完関数を呼ばない。
**修正方針:** unit テストで、`WP_Translation_File` の無い環境として最小の `MO` stub を用意し、同梱 .mo のパス・戻り値の扱い・他ドメイン/訳済み/ファイル無しの素通しを確かめる。
